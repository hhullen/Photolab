Photolab controls information

Files operating controls

  • Use File->load to load new image (.jpg, .pgn, .bmp) from selected directory.
  • There are some images preloaded in Photolab which can be found in Edit-> below menu separator.
  • Use File->save to save image file in selected directory. Photolab save images in format which loaded image has.

View space controls

  • Use Mouse wheel to scale image.
  • Drug mouse with LEFT mouse button pressed to shift cutter line.
  • Drug mouse with RIGHT mouse button pressed to move image in view space.
  • Use Edit->reset to set view into default state

Effects control

All available effects can be found in Edit menu.
